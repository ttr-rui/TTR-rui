# 设计文档
## 模块划分

| 模块 | 职责 | 关键函数 |
|---|---|---|
| `main.py` | 参数解析、调度、异常兜底 | `main()`、`check_plagiarism()` |
| `src/file_io.py` | 读原文/抄袭版、写答案文件 | `read_text()`、`write_answer()` |
| `src/tokenizer.py` | 分词、去停用词 | `tokenize()`、`remove_stopwords()` |
| `src/similarity.py` | 计算 TF-IDF 余弦相似度 | `cosine_similarity()` |
| `src/exceptions.py` | 自定义异常体系 | `PaperCheckError` 等 |
